# UI and UX Regression Testing Strategy

This document captures the UI and UX regression testing strategy for Renewal / Notice Date Tracker.

## Focus

- dashboard layout and key metrics visibility
- contract table behavior
- filter behavior
- create contract page usability
- auth screens
- settings screens
- pricing page
- notice banners
- empty states
- error states
- contract detail and review screen
- reminder forms
- admin panels

## UX Regression Rule

Do not visually test everything. Visually test the surfaces where layout, hierarchy, and state communication directly affect trust, conversion, or operational clarity.

## Manual QA Rule

Manual QA should focus on ambiguity, clarity, recovery, and cognitive load, not just whether a button technically works.
