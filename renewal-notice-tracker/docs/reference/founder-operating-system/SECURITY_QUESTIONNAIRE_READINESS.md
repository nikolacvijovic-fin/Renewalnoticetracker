# Security Questionnaire Readiness

## Focus
Prepare Renewal / Notice Date Tracker for realistic buyer security questions without pretending to be more mature than it is.

## Core areas
- auth
- roles and permissions
- tenant isolation
- backup and recovery
- data deletion and export
- audit logs
- billing and webhook safety
- vendor and subprocessor posture
- reminder reliability controls

## Best current posture
- Keep answers concrete and product-specific.
- Describe real controls, not aspirational ones.
- Use a small, credible documentation set: security overview, privacy policy, DPA, subprocessor list, retention/deletion policy, backup/recovery summary, and security FAQ.

## Biggest answer-weakening gaps
- weak restore-story evidence
- unclear deletion/export process
- incomplete audit coverage on trust-sensitive actions
- insufficiently documented subprocessors and security posture
- any overclaiming beyond real implementation
