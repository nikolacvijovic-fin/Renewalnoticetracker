# Manual QA Runbook

This document captures the manual QA runbook for Renewal / Notice Date Tracker.

## Included Checklists

- smoke test checklist
- release regression checklist
- billing checklist
- permissions checklist
- reminder reliability checklist
- import/export checklist
- extraction/review checklist
- admin/debug checklist
- settings/integrations checklist
- UX sanity checklist

## Runbook Rule

Each checklist item must state:

- steps
- expected result
- severity if broken
- whether it blocks release

## Use

Run the smoke and trust-sensitive sections on every release candidate. Use the full runbook for release validation and incident follow-up.
