# Packaging Strategy

This document captures the corrected packaging strategy for Renewal / Notice Date Tracker.

## Critique Of Current Packaging

- The strongest improvement is moving monetization toward `active tracked contracts`.
- The weakest legacy gates are `exports` and `monthly_digest` as primary commercial levers.
- Entry plan must stay operationally useful or conversion will collapse.
- Growth should monetize coordination depth, not just miscellaneous feature volume.
- Top tier should monetize governance, security, and scale instead of random complexity.

## Corrected Packaging Structure

### Core Workflow
- Entry:
  - contract upload and AI extraction
  - manual review and correction
  - owner assignment
  - renewal decisions
  - basic reminders
  - dashboard visibility
  - bounded by active tracked contract cap
- Growth:
  - same workflow
  - higher contract band
  - deeper operational usage across departments
- Top tier:
  - same workflow
  - custom contract bands
  - governance controls around portfolio use

### Team Collaboration
- Entry:
  - 5 included editor seats
  - unlimited viewers
  - lightweight cross-team usage
- Growth:
  - 15 included editors
  - fuller departmental coordination
- Top tier:
  - custom included seats
  - higher-touch governance expectations

### Reminders And Escalations
- Entry:
  - single-recipient reminders
- Growth:
  - multi-recipient reminders
  - escalation chains
  - routing depth
- Top tier:
  - same plus advanced policy/governance layers

### Imports And Exports
- Entry:
  - bulk import included
  - export included
- Growth:
  - same
- Top tier:
  - same
- Service-led:
  - spreadsheet cleanup
  - mapping
  - migration remediation

### Visibility / Reporting
- Entry:
  - dashboards and due-soon visibility
- Growth:
  - stronger operational reporting
- Top tier:
  - executive and governance-ready visibility
- Add-ons:
  - reporting package
  - quarterly review package

### Admin / Security
- Entry:
  - light operational admin
- Growth:
  - stronger admin tooling
- Top tier:
  - SSO
  - approval controls
  - governance/security layers

### Integrations
- Entry:
  - email delivery
- Growth:
  - Slack / Teams delivery
- Top tier:
  - same with stricter governance expectations

### Support / Onboarding
- Add-ons:
  - onboarding package
  - admin/training package
- Service-led:
  - spreadsheet cleanup/import
  - renewal operations setup
- Top-tier implementation:
  - bundled or discounted

## What Belongs Where

### Entry Plan
- upload and AI extraction
- review/correction
- owner assignment
- renewal decisions
- single-recipient reminders
- dashboard visibility
- import/export
- templates
- 5 included editors
- unlimited viewers
- active tracked contract cap

### Growth
- higher contract band
- more included editors
- multi-recipient reminders
- escalation chains
- Slack / Teams
- richer operational admin depth
- multi-department coordination
- playbooks and collaboration depth

### Top Tier
- custom contract bands
- governance and approval controls
- SSO / security requirements
- higher-touch implementation
- portfolio-level operational oversight

## Usage-Gated

- active tracked contracts
- included editor seats, only after generous inclusion thresholds
- future post-Growth expansion bands

## Add-Ons

- quarterly review package
- reporting package
- onboarding package
- admin / training package

## Service-Led

- spreadsheet cleanup / import remediation
- renewal operations setup
- higher-touch rollout and migration work

## Weak Current Gates

- exports as a primary paywall
- monthly digest as a primary paywall
- any future attempt to monetize viewer access
- any packaging logic more tied to UI trivia than operational depth

## Best Natural Upgrade Triggers

- approaching active tracked contract cap
- needing multi-recipient reminders
- needing escalation chains
- needing Slack / Teams delivery
- cross-department rollout
- wanting executive-ready reporting
- wanting recurring portfolio review
- adding more operational editors

## Best Expansion Logic

- first expansion axis: active tracked contracts
- second expansion axis: coordination depth
- third expansion axis: governance / security
- sidecar revenue: add-ons and services that reinforce adoption

## Fastest Profitability Wins

- keep Entry operationally useful
- move more pressure onto contract-band expansion
- make Growth clearly about coordination depth
- keep services tightly scoped and templatized
- reserve governance and security for the top tier

## Cut For Discipline

- drafting and negotiation drift
- enterprise approval logic before top-tier demand is real
- integration sprawl without monetization logic
- packaging complexity that does not create real upgrade intent
