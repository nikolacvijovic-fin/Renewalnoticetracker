# Conversion Strategy

## Where Value Becomes Real

Value becomes real when a team reviews one contract, assigns one owner, and sees one live renewal or notice obligation in the dashboard workflow.

## First-Value Milestone

One reviewed contract with an owner and a visible deadline.

## First Paid-Value Milestone

The user needs broader portfolio coverage, team coordination, or operational routing that exceeds the entry plan.

## Best Upgrade Prompt Moments

- approaching tracked contract cap
- needing multi-recipient reminders
- needing Slack or Teams delivery
- trial expiry after activation
- expanding beyond a single-owner workflow

## Best Feature Gate Moments

- adding the next contract after hitting tracked capacity
- asking for multi-recipient routing
- asking for Slack or Teams delivery
- needing deeper cross-team accountability

## Trial Recommendation

Use a 14-day trial for SMB and lower mid-market self-serve accounts, then apply sales assist for higher-fit accounts that show real activation.

## Top Conversion Experiments

- dashboard checklist versus passive dashboard
- trial-expiry prompts only after first value
- upgrade CTA copy tied to team coordination
- owner-assignment prompt before billing CTA
- import completion prompt offering setup help
