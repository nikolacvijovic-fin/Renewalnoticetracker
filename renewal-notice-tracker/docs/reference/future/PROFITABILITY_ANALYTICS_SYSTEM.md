# Profitability Analytics System

## North Star Metric

Active tracked contracts with reviewed dates and assigned owners in paying workspaces.

## Activation Metric

Workspaces that reach one reviewed contract, one owner assigned, and one live obligation surfaced.

## Core Metric Groups

- revenue metrics
- pricing metrics
- conversion metrics
- retention metrics
- expansion metrics
- support cost metrics
- margin metrics
- churn indicators
- vanity metrics to ignore
