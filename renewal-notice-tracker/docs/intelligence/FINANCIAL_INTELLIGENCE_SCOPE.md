# Financial Intelligence Scope

This future layer is for read-only financial intelligence based on trusted workflow state.

Allowed future direction:

- renewal-value-at-risk rollups
- exposure summaries from trusted contract values
- portfolio-level financial reporting based on reviewed truth

Not allowed:

- editing contract value through intelligence output
- triggering billing changes
- activating reminders
- bypassing review or owner gates

Activation requirement:

- financial inputs must come from reviewed workflow state and intentionally modeled value fields
- every insight must include trust level, data quality, sources, calculation basis, warnings, and confidence score
